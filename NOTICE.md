This package contains code and tables of facts only. It ships no Minecraft assets.

The textures, models and other resource pack files this tool reads and writes are the property of Mojang AB /
Microsoft and are covered by the [Minecraft EULA](https://www.minecraft.net/eula) and the
[Minecraft Usage Guidelines](https://www.minecraft.net/usage-guidelines). Whoever runs the tool is responsible for
how its output is used and redistributed.

Sources the tool can read:

- an installed Bedrock client (your own copy of the game)
- [Mojang/bedrock-samples](https://github.com/Mojang/bedrock-samples), Mojang's published vanilla packs
- [ZtechNetwork/MCBVanillaResourcePack](https://github.com/ZtechNetwork/MCBVanillaResourcePack), community copies of
  the vanilla pack of older versions

The tables of `data/` are facts the Bedrock client and server report about their blocks and items (render shapes,
layers, tint methods, data value layouts, item icon names), keyed by block and item name.
